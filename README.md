# VOXEL

方塊世界 · 種田 · 季節 · 日夜 · 怪物。一個整個寫在單一 HTML 檔裡、直接在瀏覽器玩的方塊沙盒兼種田遊戲:不用任何函式庫、不用建置。翻土、播種、澆水、收成,把作物兩兩雜交培育出 32 種作物,拿去市集賣或做成料理。畫面由顯示卡(WebGL2)對每個像素做光線投射(raycasting),方塊有 16×16 像素材質、陰影和角落暗部,作物會隨風搖、池塘會反光、四季會換顏色;瀏覽器不支援時會自動改用 CPU 渲染。

**線上遊玩:<https://chyhhwen.github.io/voxel/>**

## 開始玩

- **線上**:打開上面的網址。
- **本機**:直接用瀏覽器打開 `index.html`。
- 電腦用鍵盤滑鼠、手機平板用觸控都能玩;手機橫放畫面最大。
- 近年的 Chrome、Edge、Firefox、Safari 都支援 WebGL2,會看到有材質的畫面。
- 新世界的出生點旁邊有一個小池塘和一塊 3×3 的菜園,背包裡有鋤頭、澆水壺、種子和兩個麵包,可以直接開始種。

## 種菜

### 基本流程

1. **翻土**:拿鋤頭對草地或泥土按右鍵,變成耕地(對著草地上的雜草也可以)。鐵鋤和鑽石鋤一次翻 3×3。
2. **播種**:拿種子對耕地按右鍵。
3. **保持濕潤**:乾的耕地作物只長 1/4 速度。讓耕地變濕的方法:
   - 水方塊 4 格內(同一層或低一層)的耕地一直是濕的
   - 灑水器讓周圍 3×3、高級灑水器讓周圍 5×5 的耕地一直是濕的(會看到噴出的水花)
   - 澆水壺一次澆 3×3,維持一整天
   - 下雨時,頭上沒被擋住的耕地會變濕
4. **收成**:作物成熟後對它按右鍵,拿到作物(1–3 個),而且會自動補種;偶爾多掉一顆種子。用左鍵拔的話,成熟的照樣收成、不會補種但一定掉種子;沒熟的拔起來會退回種子。番茄、甜椒、草莓、藍莓、茶、咖啡、葡萄等收成後會從半熟再長回來,不用重種。

準心對著作物會顯示名字、生長進度和現在缺什麼(缺水、非當季、太暗……)。

### 生長速度

作物成熟要遊戲時間 4–16 小時(遊戲 1 小時 = 現實 1 分鐘),速度會乘上:

| 狀況 | 速度 |
| --- | --- |
| 耕地是乾的 | ×0.25 |
| 不是這個季節的作物 | ×0.25(溫室裡不受影響) |
| 太暗(晚上又沒有火把照到) | ×0.4 |
| 稻米、甘蔗、芋頭的耕地旁邊沒有水 | ×0.1 |
| 施過肥 | ×1.5 |

- **溫室**:作物頭上第一個實心方塊是玻璃,就不受季節影響。冬天想種夏天的作物就蓋溫室。
- **火把**:晚上作物會長得比較慢,在田邊插火把就能整晚照常長。
- **肥料**:在市集買,或用暗核、小麥合成;對耕地按右鍵施肥。施過肥的耕地收成時有一半機率多一個。

### 時間與季節

- 一天 24 分鐘。晚上對著床按右鍵可以睡到早上,睡覺的這段時間作物照樣長(有火把照的會整晚全速長)。
- 每季 2 天,春 → 夏 → 秋 → 冬輪替,畫面右上角會顯示季節和第幾天。
- 草和樹葉跟著季節變色:春天有些樹會開粉紅色的花,夏天綠得比較深,秋天整棵樹變紅或變黃,冬天露天的地面、樹頂會積雪(溫室裡和耕地不會)。
- 每天會自動決定天氣,冬天比較常下雪;按 R 也可以自己換。
- 不合季節的作物在市集賣價多 30%。

### 雜交培育

把**兩株成熟的不同作物**種在一格空耕地的兩側(上下或左右相鄰),過一段時間那格空地就可能長出牠們的雜交種。兩株一樣的作物也會像這樣繁殖出同一種作物。空耕地是濕的機率比較高,吃「雜交↑」效果的料理會再提高。

- 32 種作物分成 5 階。第 1 階的 8 種可以直接在市集買種子,其他 24 種要靠雜交發現,發現以後市集就能買到它的種子。
- 發現新品種時會跳出通知。背包的「培育圖」分頁會畫出整張雜交關係圖:沒發現的作物顯示「?」,兩個親代都發現了就會告訴你配方。
- 第 4、5 階的金南瓜、星光果、月光花成熟時會發光,晚上可以照亮田地。

第 1 階作物:

| 作物 | 季節 | 成熟(小時) | 種子 | 賣價 | 備註 |
| --- | --- | --- | --- | --- | --- |
| 小麥 | 春夏秋 | 4 | 3 | 6 | 也能做床和肥料 |
| 胡蘿蔔 | 春夏秋 | 4 | 4 | 8 | |
| 馬鈴薯 | 春夏秋 | 5 | 4 | 9 | |
| 番茄 | 夏 | 6 | 6 | 10 | 收成後會再長 |
| 玉米 | 夏秋 | 7 | 6 | 12 | |
| 高麗菜 | 春秋冬 | 5 | 5 | 10 | 少數冬天能種的 |
| 稻米 | 夏 | 6 | 5 | 11 | 耕地要緊鄰水 |
| 甘蔗 | 夏秋 | 6 | 5 | 10 | 耕地要緊鄰水 |

之後還有第 2 階 9 種、第 3 階 8 種、第 4 階 5 種、第 5 階 2 種,越高階長得越久、賣得越貴(第 5 階一個 350–400 金幣)。

### 雜草

草地上會慢慢長出雜草,拔掉有 35% 機率撿到種子,通常是當季的作物。冬天雜草會枯掉。

## 背包分頁

按 I / Tab / 🎒 打開,上方有五個分頁:

- **背包**:整理物品、合成。
- **市集**:左邊賣、右邊買。作物、種子、料理和一部分方塊都能賣;可以買鋤頭、澆水壺、水桶、肥料、灑水器、床、玻璃、木板、火把,以及所有已發現作物的種子。錢不夠的會變灰。
- **料理**:25 道料理,材料夠了按「煮」。拿著料理按右鍵吃掉會回血,很多還有限時效果(時間顯示在愛心上方):

  | 效果 | 作用 |
  | --- | --- |
  | 🏃 跑快 | 移動速度 ×1.35 |
  | 🦘 跳高 | 跳得比較高 |
  | 🌙 夜視 | 晚上也看得清楚 |
  | ⛏ 挖快 | 挖掘速度 ×1.6 |
  | 🌾 豐收 | 每次收成多一個 |
  | 🧬 雜交↑ | 雜交機率 ×2.5 |
  | 💛 生命+2心 | 生命上限多兩顆金色的心 |

- **培育圖**:依階分成五欄,每個雜交種都有兩條線連到它的親代。點一個作物看季節、成熟時間、賣價、收成次數,以及它能再培育出什麼。
- **農場圖**:從正上方看整個世界,一格一個方塊:乾 / 濕耕地、作物(越大越接近成熟,成熟的有白圈)、水、灑水範圍、溫室、怪物和你的位置。點一格看詳細資料和大約還要多久成熟。

## 玩法

### 世界

- 32 × 32 × 32 格,四周圍著挖不掉的玻璃牆。
- 地表是草地,下面是泥土、4 層沙土,再往下是石頭。石頭裡有礦:煤礦到處都有,鐵礦多在深處,鑽石礦只在最底下 5 層。
- 草會慢慢長到露天的泥土上,被方塊蓋住就變回泥土。
- 有日出日落、星星、月亮和飄動的雲。
- **水**:用水桶可以把水舀起來、倒到別的地方。水方塊可以游泳:在水裡走得比較慢、會慢慢往下沉,按住空白鍵往上游;頭潛到水裡畫面會變藍。

### 挖掘與工具

挖下來的方塊會進背包(一格最多疊 64 個),準心最遠搆得到 7 格。石頭和礦要有夠好的工具才挖得動:

| 方塊 | 需要 | 最快的工具 | 掉落 |
| --- | --- | --- | --- |
| 草地 | — | 鏟 | 泥土 |
| 泥土、沙土、耕地 | — | 鏟 | 泥土 / 沙土 |
| 木頭、木板 | — | 斧 | 本身 |
| 樹葉、玻璃、火把、灑水器、床 | — | — | 本身 |
| 石頭 | 木鎬以上 | 鎬 | 石頭 |
| 煤礦 | 木鎬以上 | 鎬 | 煤炭 |
| 鐵礦 | 石鎬以上 | 鎬 | 鐵錠 |
| 鑽石礦 | 鐵鎬以上 | 鎬 | 鑽石 |

用對的工具,木製快 2.9 倍、石製 4.8 倍、鐵製 6.7 倍、鑽石 8.6 倍。

### 怪物與生存

- 晚上在黑暗處會生怪,牠們會追過來、靠近就攻擊。火把周圍約 7 格內不會生怪。
- 怪物白天曬到太陽會被燒死。打倒會掉 1–2 個「暗核」,可以合成火把或肥料。
- 生命是 10 顆心,受傷後每 4 秒回半顆,吃料理回得更多。死掉會在出生點重生,背包保留。
- 怪物有 12 點血。劍的傷害最高(木 5、石 6、鐵 8、鑽石 9,徒手 1),弓一箭 7 點。
- 只想安心種田的話,在設定打開「和平模式」,就完全不會有怪物。

### 創造模式

按 C 或在設定切「模式」:快捷欄變成無限的方塊(滾輪翻頁,也有木板、灑水器和床)、方塊一碰就碎、不會受傷,怪物也不會出現或追人。背包內容原封不動,切回生存就回來了。

## 設定

在選單的「設定」裡:

- **滑鼠 / 觸控靈敏度**、**Y 軸反轉**
- **陰影**:太陽投影(也可按 G)
- **畫質**:自動 / 低 / 中 / 高 / 超高
  - 顯示卡渲染時:低 = 螢幕解析度的一半、中 = 3/4、高 = 螢幕解析度、超高 = 高解析度螢幕的完整像素(一般螢幕則是 1.5 倍超取樣,邊緣更平滑)。「自動」從高開始,畫面太卡就降一檔;如果降了也沒變順(例如手機省電模式鎖 30 fps),會退回原來那檔
  - CPU 渲染時:中就是原本的 280×168 像素,「自動」依效能在低、中、高之間調整
- **顯示 FPS**:右上角顯示幀率、渲染方式和解析度
- **操作說明**:左上角的說明文字(也可按 H)
- **模式**:生存 / 創造
- **和平模式**:不生怪,已經在的怪物也會消失

除了模式以外,設定都會記在瀏覽器裡。

## 存檔

每玩 8 秒自動存一次,打開選單、切換分頁、睡覺或關閉網頁時也會存。存檔在瀏覽器的 localStorage,只存在這台電腦的這個瀏覽器裡,清除網站資料就會不見。要重新開始,在選單按「重新產生世界」(按兩次確認)。

- 農場的資料(金幣、第幾天、作物生長進度、耕地濕度、已發現的作物、收成次數、料理效果、天氣)另外存在 `voxelF`,世界、背包等還是原本的格式。
- 作物只在遊戲開著(或睡覺)的時候長,關掉網頁不會繼續長。
- 舊版的存檔可以直接讀:第一次讀進來時,露天的泥土會變成草地;還沒有農場資料的存檔會拿到一組入門工具(鋤頭、澆水壺、種子)。

## 技術說明

- 整個遊戲就是 `index.html` 一個檔案,純 JavaScript,用 WebGL2 和 Canvas 2D。
- **顯示卡渲染(預設)**:片段著色器對每個像素從眼睛射出光線,用 DDA 在 32×32×32 的方塊格子裡逐格前進。世界和火把光各是一張 3D 貼圖,另外一張 32×32 的貼圖記每一欄最高的實心方塊(積雪用)和所屬的樹(整棵樹一起變色),方塊有改動時重新上傳。
  - 材質:開場時用程式畫出 16×16 的像素材質(方塊、耕地、水、木板、灑水器、床、挖掘裂痕,以及 32 種作物 × 4 個生長階段、雜草),依距離選 mipmap 等級
  - 作物是穿過格子的 4 片「井」字形貼圖、雜草是交叉的 2 片,透明的地方看得穿,頂端會隨風搖,也會投下斑駁的影子
  - 水面比方塊低 1/8,有波紋、依角度(Fresnel)反射天空和太陽,底下的東西看起來越深越藍;頭在水裡時整個畫面像在水中
  - 床和灑水器是幾個小方盒組成的模型
  - 光影:天空環境光、每個像素一條往太陽的陰影光線(穿過樹葉和作物縫隙會變成斑駁的影子)、Minecraft 式的角落暗部(AO)、平滑內插的火把光(成熟的發光作物也算光源)、距離霧
  - 其他:四季的草色和樹色、冬天積雪、樹葉可以透光、玻璃有框、火把是有光暈的小棍子、方形太陽和月亮、怪物是立體的方塊人(眼睛會發光)、準心指到的方塊有外框和裂痕
  - 光線前進時只記錄打到什麼、在哪裡,材質和光照最後才算一次,減少每個像素要保留的暫存值;在測試環境裡,加了作物、水面和季節之後的速度跟加入種田前差不多
- **CPU 渲染(備援)**:同樣的光線投射用 JavaScript 算,寫進 `ImageData`。方塊是純色(草和樹葉也會跟季節變色),作物和雜草照樣用貼圖畫出來,水會讓後面的東西變藍。瀏覽器沒有 WebGL2、或顯示卡掉線時自動切換;網址加上 `?cpu` 可以強制使用。
- 兩種渲染上面都用 Canvas 2D 畫手上的東西、雨雪、灑水器的水花、翻土澆水收成時的小粒子、挖掘進度和提示;快捷欄、背包、市集和培育圖的圖示也是同一套材質做的。
- **可調參數**:程式裡的 `GFX`:

  ```js
  const GFX = { steps: 100, shadowSteps: 48, fog: true, shade: [.86, 1, .74] };
  ```

  `fog` 是距離霧、`shade` 是 x / y / z 三個方向的面明暗(兩種渲染都用);`steps` 是 CPU 光線最多走幾格、`shadowSteps` 是 CPU 陰影光線長度。在 CPU 渲染下改成 `{ steps: 24, shadowSteps: 16, fog: false, shade: [1, 1, 1] }` 就是最早那版的畫面。
- 作物、雜交配方、料理和市集的資料都寫在程式裡的 `CROPS`、`DISHES`、`SHOP` 陣列,要調整數值或加新作物改那裡就好。
- 程式碼依序分成:DOM、世界、火把光、物品與作物、材質與圖示、存讀檔、玩家、挖掘與農具、生物、種田、天空、CPU 渲染、顯示卡渲染、疊加層、HUD 與面板、農場介面、選單與設定、輸入、主迴圈。

## nettest.html:多人連線可行性測試

為之後的多人連線做的測試頁,確認遊戲放在 GitHub Pages(https)上時能用哪種方式連線:

1. 環境檢查(https、secure context、有沒有 WebRTC)
2. `ws://` 會不會被混合內容規則擋掉
3. `ws://127.0.0.1` 回環例外
4. ICE candidate 掃描:本機位址是真實 IP 還是 mDNS `.local`,Radmin 虛擬網卡有沒有出現
5. 同一頁內的 DataChannel 回環
6. 兩台機器手動交換 offer / answer 的 WebRTC 實測,不需要 signalling 伺服器

要從 https 網址開才準:<https://chyhhwen.github.io/voxel/nettest.html>。測試 1–5 一台機器就能跑,測試 6 需要兩台(建議在 Radmin 連線狀態下)。
